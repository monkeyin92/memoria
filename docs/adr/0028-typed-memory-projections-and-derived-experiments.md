# 类型化记忆投影与派生实验索引

Memoria 将 `memory_kind`（语义、情节、程序、关系）与 `domain_category`（工作、家庭等主题）
分开，`item_kind` 只表示声明、情节、知识或技能等投影形态；工作记忆继续按话轮动态组装，
不写入长期表。PostgreSQL 证据账本仍保存不可变来源与主人审批证据；Episode、统一记忆搜索
文档、pgvector、Mem0 影子结果和 TurboVec 都是可删除重建的派生数据。

Skill definition/version/run 与 Digital Self 版本相同，属于有证据关联的持久业务状态，不能被
通用记忆投影重建直接截断；灾备时保留这些表，再从当前批准版本重建 `kind=skill` 的搜索文档。
Skill 必须经主人批准和本次运行确认后才可执行，失败按已完成步骤逆序补偿。Mem0 只能写隔离
实验结果，TurboVec 只有在固定评测集同时满足召回、延迟、真实常驻内存、同步和重建门槛后
才允许成为可选索引。这样牺牲了“接入组件即生效”的速度，换取来源、撤销、跨账户隔离、
灾备和回滚语义不被第三方存储模型绕过。
