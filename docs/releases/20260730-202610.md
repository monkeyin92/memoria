# 对话首页与无障碍文字对话 Release 20260730-202610

## 目标

- 首页把吉祥物作为视觉中心，取消“图片可点、下方又有按钮”的重复入口。
- 语音会话只保留一个主按钮：空闲时开始，通话中变为结束；移除静音、停止播放和含义不明的
  手势按钮。
- 增加不申请麦克风、不录音、不播放声音的文字对话，为听力障碍或不便使用语音的用户提供
  完整替代路径。

## 实现

- H5 与小程序均提供“开始语音对话 / 使用文字对话”两个清晰入口；语音激活后只显示一个
  “结束语音对话”按钮。文字模式提供带标签的输入框、发送与退出操作，并保留本次最近 12 条
  权威文本。
- 吉祥物继续复用权威 `assistant_expression` 与既有 generation fence，增加呼吸、眨眼、
  状态光环和说话动作；吉祥物本身改为非交互图像，避免错误点击暗示。
- H5 文字输入使用 LiveKit `lk.chat`；小程序通过媒体网关新增有界 `text_turn` 控制事件，
  网关只将其转发给当前已绑定账户 participant。
- Agent 的自定义 text input 回调把已认证账户文字绑定为 owner，复用既有
  `UtteranceRouter`、ResponsePlan、伙伴个性、安全规则和 generation fence。文字会话关闭
  Agent 音频输出，助手终稿以 `text_delivered=true / heard=false` 发布，避免伪造“已经播放”。
