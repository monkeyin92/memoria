## 发布内容

- Agent 与 H5 的 `transcript_delta.session_id` 契约拒绝空会话标识。
- 新增 `packages/contracts/miniprogram-media.json`，由 Python 与 JavaScript 共同约束
  hello、ready、控制事件、PCM golden frame 和固定 `20 ms / 960 bytes` 下行帧。
- Control API 的小程序 URL、ticket 与响应模型收口到
  `services/control_api/app/miniprogram_gateway_session.py`。
- 小程序 Socket 断开后立即停止录音；mic 关闭压过迟到的
  `RecorderManager.onStart`；同步发送失败不提交 sequence。
- 播放器校验固定帧长、首批使用 lead、duck/restore 使用短 ramp，避免硬切 click/pop。
- `audio_reset` 成为不可丢失 barrier；匹配 generation 的播放中断只抑制对应 AEC
  reverse reference。
- 系统录音中断结束后发送 `uplink_discontinuity(next_sequence)`，同一 WSS 会话重置
  半帧、sequence 与 AEC 时序后恢复。
