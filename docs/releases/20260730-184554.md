# 实时信息与伙伴个性 Release 20260730-184554

## 目标与根因

- 修复“今天星期几 / 现在几点”由模型自行判断而可能答错的问题；原运行时没有日期、时间或天气
  function tool，只有 Qwen 请求的 `enable_search=true`，客户端时区也没有进入每轮响应计划。
- 修复五个伙伴首句统一为“嗨，我在呢”，以及正文和声音只换音色、没有稳定消费伙伴个性的
  问题。根因是欢迎语在 Agent 入口硬编码，普通 `SpeechPlan` 也不读取 `companion_id`。

## 实现

- 新增共享实时信息入口：北京时间的日期、星期与分钟级时间由服务端确定性直答；未提供城市的
  天气问题先追问城市；包含城市的天气以及新闻、行情、政策、交通等变化信息收到权威本地时间
  和“先联网、无可靠结果不猜”的每轮指令。Control API 失败时 Agent 本地安全降级复用同一规则。
- `CompanionDefinition` 成为单一伙伴行为配置：五个伙伴各有独立欢迎语、可执行的措辞规则、
  TTS 指令和有界默认语速/情绪。Control ResponsePlan、Agent fallback、首次欢迎语和普通
  `SpeechPlan` 共用该配置。
- 优先级保持为：危机与安全规则 > 用户明确语音命令 > 当轮语义情绪 > 伙伴默认风格；桃喜不会
  在严肃场景乱笑，沉稳伙伴也不会覆盖用户“说快一点”等明确命令。
- 既有五个豆包设计音色映射没有修改；本轮只切 runtime，H5 保持 `20260730-171321`，小程序
  体验版保持 `0.8.63`，未重新上传、未提审、未正式发布。

- 自动化与 Provider canary 不能证明真实手机扬声器上的俏皮度、沉稳度、停顿和情绪强度；需要在
  下一次实际对话中分别切换至少桃喜、阿序和玄墨做主观听感验收。

  可靠结果时只说不知道。若未来需要定位到设备当前位置，必须另行设计明确授权的定位入口。
