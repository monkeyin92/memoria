## 自建 LiveKit 拓扑

- 信令/API 由 Nginx 的 `/rtc`、`/agent`、`/twirp/` 转发到主机回环 `127.0.0.1:7880`。
- LiveKit 与 Memoria Agent 共用 `memoria_default` Docker 网络；Agent 媒体使用内部 UDP，不绕公网 NAT。
- 公网 `7882/UDP` 保留为优先媒体路径。
- 公网 8443 同时承载 HTTPS 与 RTC/TCP：Nginx stream 将 TLS 转到 `127.0.0.1:9443`，将非 TLS ICE/TCP 转到 `127.0.0.1:8444`，再进入 LiveKit 容器 8443。
- 未保留内置 TURN。腾讯云公网 IP 通过 NAT 提供且 Docker bridge 下 TURN relay 端口无法形成可靠同机回环；直接复用 8443 的 LiveKit RTC/TCP 更短、更可验证。
- `DEPLOYMENT_PROFILE=cn_self_hosted`，Turn Detector 为 `v1-mini`，Adaptive Interruption 与 preemptive generation 均关闭。
