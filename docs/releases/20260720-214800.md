# Runtime/H5 Release 20260720-214800

## 根因与修复

- 点击伙伴后，Agent、LiveKit 音轨和浏览器播放解锁都已成功，但首句调用 `session.generate_reply(instructions=...)` 时没有末尾 user message。DashScope Qwen 因 role 序列非法返回 400，LiveKit 将其包装为 `APIConnectionError`，所以 CosyVoice 从未收到首句文本。现改为固定单流 `session.say` 欢迎语，完全绕过空会话 LLM 请求。
- 新增的 `TargetSpeakerFocus` 把 CAM++ shadow `guest/ambiguous` 直接作为普通聊天硬门禁。现场 profile 仍处 shadow-only，实时分数没有经过 FAR/FRR 校准，账户主人也会被丢弃。现将策略分为两个上下文：正式 `guest` 在普通聊天和播放期均阻断；shadow 结果只在播放期阻止抢话，普通聊天 fail-open，私人记忆、长期写入和敏感操作权限仍为 `uncertain`。
