# 20260812-134635 Release

## 状态与范围

- 基于生产健康版本 `20260812-123053`，修复 ESP32 Path 2 固定欢迎语已经生成 PCM、但共享
  LiveKit Bridge 没有获得 generation-bound `assistant_state=speaking`，从而按安全合同丢弃音频
  的问题。修复放在固定 `AgentSession.say` 的统一入口，不让设备网关猜测代次或缓存未授权首帧。
- 新的 `FixedSpeechPlayer` 在调用 `session.say` 前捕获完整 GenerationFence，复用 Runtime
  speaking 生命周期，并等待 `assistant_state` 与受控半双工 input policy 都发布完成；播放结束
  后在同一 fence 恢复 `listening`。声纹登记提示恢复 `speaker_enroll`，不会短暂开放普通会话。
- 异常或取消会尽力停止底层 speech handle 并恢复当前 generation；若任务已过期，finally 不会清除
  新 generation 的 speaking，也不会发布迟到的 listening。固定 TTS speech plan 也绑定到同一
  fence。
- 共享桥接继续以 `assistant_state=speaking` 作为唯一音频放行信号，并在 `listening` 后停止
  转发；设备协议仍统一映射内部 generation `N` 到正数 generation `N+1`。本次不含数据库
  DDL、数据修订、固件、env 或 H5 变更，回滚目标为 `20260812-123053`。
