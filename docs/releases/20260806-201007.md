# StreamCore 媒体边缘与精确播放 ACK Release 20260806-201007

## 发布范围

- H5 StreamCore 远端音频通过 `MediaElementAudioSourceNode -> AudioWorkletNode`
  建立 generation-fenced 软件播放 watermark。静音、seek、flush、重连、关闭和
  Worklet 不可用时均保持 fail-closed 或 `approximate=true` 回退。
- Python Voice Core 保留 `MediaVoiceCoreRegistry` facade，并将 lifecycle、ingress、
  projection、commit、turn 与 output 责任拆分；Go Media Edge 按 WHIP signaling、
  WebRTC audio/DataChannel、bridge shadow、actor mailbox、session/server 拆分。
- 实时天气查询优先使用无密钥 Open-Meteo，先播“稍等，我查询一下。”，查询结果仅在原
  generation 仍有效时回告；其他实时查询保持 Qwen forced-search 的 fail-closed 行为。
- Media JWT 支持 Ed25519/EdDSA `kid`/JWKS 验证和可选私网 health/metrics listener；
  HS256 仅保留迁移 fallback。

## 生产边界

- 生产仍固定 `MEDIA_RUNTIME_DEFAULT=livekit`、`STREAMCORE_EXPERIMENT_PERCENT=0` 和
  `MEDIA_EDGE_INTERACTION_AUTHORITY=python_authoritative`；本 release 不启用
  `go_authoritative` 或 media-runtime profile。
- `approximate=false` 仅代表 AudioWorklet 软件播放图处理了对应 sample watermark，不是
  DAC、扬声器或用户实际听到声音的证明。
- 真实 provider/TURN、跨主机浏览器播放、硬件 AEC、多实例 ownership、容量/Chaos、灰度与
  回滚演练继续是独立外部门禁，不能由本次本地测试替代。
