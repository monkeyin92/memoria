## 部署陷阱固化

- data compose 必须使用 `--project-directory /opt/memoria/current/infra`，不能指向 release 根目录；`memoria-data.production.yml` 的脚本 bind mount 使用 `create_host_path: false`，路径错误会立即失败。
- 首次部署先由 runtime Compose `create --no-build` 创建带 Compose label 的 `memoria_default` 网络，再启动 data、LiveKit 和 runtime；禁止无标签手工 `docker network create memoria_default`。
- 上述约束已写入 `docs/production-deployment.md`，并由 `services/control_api/tests/test_production_compose.py` 锁定。
