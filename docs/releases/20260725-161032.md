# 小程序伙伴资源与语音上行修复 Release 20260725-161032

## 发布目标

- 修复体验版中伙伴机身图未随包发布，导致真机只显示 CSS 面部占位的问题。
- 修复小程序媒体网关发布的上行音轨未标记为 LiveKit `SOURCE_MICROPHONE`，导致 Agent 只播放首句、却不消费用户语音的问题。

## 根因与修复

- 小程序主页曾通过动态路径引用 `assets/companions/alpha` 图片；该目录没有进入已提交的体验包源，且动态引用不能作为可靠的打包依赖依据。客户端改为对五个已批准伙伴使用字面量图片路径，并增加非空资源回归测试。
- 网关创建了本地 PCM 音轨，但发布时未指定音源。LiveKit Agents 的输入链路只订阅 `SOURCE_MICROPHONE` 音轨，因此网关收到的上行帧未进入 Agent。网关现以 `TrackPublishOptions(source=SOURCE_MICROPHONE)` 发布。

## 发布前验证

- 网关 bridge/app/protocol 定向测试通过；Ruff 与 strict mypy 通过。
- 小程序逻辑测试 9/9 通过，主页脚本语法检查与 `git diff --check` 通过。
- 微信开发者工具匿名会话实测主页完整显示星澜机身图片，控制台没有编译错误。

## 发布边界

- runtime 只变更四个固定 amd64 镜像；H5 无源码变更，仍按标准工件与 smoke 门禁验证，但不切换 H5 软链。
- 体验版随后上传为 `0.8.40`，不提交审核或正式发布。
- 真机的麦克风采集、扬声器/AEC、弱网、前后台和蓝牙仍需在新体验版上复验；开发者工具模拟器不提供可用于此结论的真实录音帧。
