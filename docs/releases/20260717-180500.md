# Release 20260717-180500

## 目标

按顺序完成 P0 1–4：主轨附和、CosyVoice 副语言标签、Omni Flash/Plus silence·threshold A/B、状态相位可观测。

## 变更

### P0-1 主动附和轨
- 默认 `LISTENER_CUES_ENABLED=true`、`LISTENER_CUE_PLAYBACK=main_track`。
- 附和走 `session.say(..., add_to_chat_ctx=False)`，**不进 chat、不发第二音轨**（避免 BackgroundAudioPlayer 双音）。
- `background` 模式仍可选，且必须 `LISTENER_CUE_AEC_VALIDATED`。

### P0-2 CosyVoice 细粒度标签 + DeliveryPlan
- 默认 `COSYVOICE_PARALINGUISTIC_TAGS=true`。
- 轻松笑：`[laughter]`；安排类：`[breath]`；数字可 `<strong>` 轻强调。
- 严肃语境 `supportive`：硬禁笑/吸气/强调标签并 strip。

### P0-3 Omni A/B + VAD 扫表
- Flash / Plus 会话返回 `ab_profile` 与 `ab_scan`（候选 silence/threshold）。
- Plus 默认 `silence=650` / `threshold=0.45`（Flash 800 / 0.5），均可 env 覆盖。
- H5 上报 `omni_ab_profile` 诊断。

### P0-4 状态机可观测
- `InteractionPhase` 切换写日志、`interaction_phase` audio_trace、metrics `interaction_phase_total`。
- UI 事件继续带 `phase`（BACKCHANNEL / THINKING_SILENT / SPEAKING 等）。
