# H5 小程序视觉同步 Release 20260730-153343

## 目标

- 将 H5 的视觉语言同步到小程序当前的深空霓虹主题，同时保留 H5 现有语音会话、事件 fence、账户与隐私语义。
- 重排首页信息层级，补齐显式语音入口和“我的”页伙伴切换入口。
- 直接复用仓库内已审核的小程序伙伴与星空资源，避免两端继续维护不同的角色外观。

## 发布前门禁

- H5 全量测试：22 个测试文件、242 项测试通过。
- H5 production build 通过；现有 Rollup 主分片大于 500 KiB 警告仍存在，不阻塞本次视觉发布。
- 小程序全量测试：80 项通过，确认共用角色资源与小程序现有行为未回归。
- `git diff --check -- apps/h5` 通过；发布源码与 H5 工件将绑定本 release 的唯一 commit/tag。

## 生产范围

- 仅新增并原子切换 H5 静态 release；runtime 保持 `20260730-092236`，不重启 Control API、Agent、Speaker Model、Gateway、LiveKit 或数据服务。
- 切换前记录真实 H5 软链，并保留 `20260729-113831` 作为直接回滚点。
- 候选 `assets/` 按 immutable URL 规则合并历史 release：只补缺失文件，不覆盖同路径资源，不使用 `rsync --delete`。

## 回滚

- H5 故障只将 `/var/www/memoria-h5` 原子切回发布前记录的软链；不切 runtime，不恢复数据库或对象存储。
- 切回后重新验证根 H5、兼容路径、SPA、API live/ready 和旧静态资源。
