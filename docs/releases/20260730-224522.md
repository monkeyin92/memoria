# 语音话轮归并与打断止血 20260730-224522

## 发布目标

- 修复一个 LiveKit 逻辑话轮包含多个 VAD epoch 时，旧识别结果在后续两三轮才出现的结构性风险。
- 降低 H5 短插话门槛，候选插话开始时立即静音助手，并恢复不结束会话的“停止回答”兜底按钮。
- 补齐麦克风上行、FunASR 数值时序和话轮归并诊断；遥测不采集识别文本、设备 ID、标签或原始音频。
- 把话轮归并和 H5 音频遥测从既有大文件中拆成独立模块，保持 UtteranceRouter、GenerationFence
  和主人隐私权限边界不变。

## 主要改动

- 新增 `SpeechEpochAssembler`：以 ASR final segment 关联 committed turn，支持一个逻辑话轮
  合并多个 VAD epoch；迟到、陈旧或不相关 segment 进入隔离路径，不能串入下一轮。
- `DuplexRuntime` 只负责接线和 fence，话轮归并与音频 Trace 校验分别下沉到独立模块。
- FunASR final 增加 `task_epoch / sentence_id / begin_ms / end_ms / duration_ms` 数值元数据，
  供服务端对齐和诊断使用。
- H5 新增 `LiveKitAudioTelemetry`，统一采集浏览器实际麦克风设置、上行 RTP 和助手下行质量；
  `useVoiceSession` 不再直接承担 WebRTC stats 轮询。
- H5 默认 `INTERRUPTION_MIN_DURATION_S` 从 `0.45` 调整为 `0.35`；检测到候选插话时先将助手
  音量降为 0，误触发仍由既有 false-interruption 恢复路径处理。
