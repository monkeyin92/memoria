# Release 20260717-152200

## 目标

修复级联声纹登记首句「叠音 + 结尾加速」：登记提示改为固定单流 `session.say`，不再走多句 `generate_reply`。

## 变更摘要

- 登记提示与确认语使用 `_say_fixed`：`rate=1.0`、`wait_for_playout`、`interruptible=False`。
- 固定文案：`请用正常音量连续说大约四秒，可以说：我是主人，请记住我的声音。`
- 登记 PCM 仅在提示播完后开始采集，避免把 AI 播报录进声纹。
