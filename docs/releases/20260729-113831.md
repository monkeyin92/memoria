# 注册称呼与吉祥物语义表情 Release 20260729-113831

## 目标

- 新账号在 H5 和小程序首次注册时填写“怎么称呼你？”；自然对话只在已确认主人身份时使用该称呼。
- 移除个人资料中的称呼与“想让伙伴怎样陪你”编辑入口，兼容字段不再作为常规 UI 资料暴露。
- 为 H5 与小程序的伙伴缩略图补齐可见面部；助手实际播放时按照回复语义显示平静、开心、好奇或关切。
- 用受 `session_id / turn_id / generation_id / tool_epoch` 约束的 `assistant_expression` 事件连接 Agent、H5、小程序 Gateway 与小程序页面，避免迟到事件改写当前表情。

## 发布前验证

- Control API、Agent、Gateway 定向回归覆盖注册称呼、owner-only 上下文、表情决策和网关转发。
- H5 全量测试与 production build 通过。
- 小程序全量测试、JavaScript syntax、auth/home/profile WXML/WXSS 编译通过；模拟器首页和“我的”无明显遮挡，console 错误过滤为空。
- 本 release 仍须在本机重新执行完整 Python、Ruff、strict mypy、离线 E2E 与 commit-bound 工件门禁。

## 生产变更

- runtime 四个固定 `linux/amd64` 镜像、source、H5 和 manifest 必须绑定本 tag 的唯一 commit。
- Control API 将注册称呼写入 profile，并仅通过内部 session policy 交给 Agent；guest 与 uncertain 不得获得主人称呼。
- H5 必须在 runtime/readiness/Provider/Nginx 门禁通过后最后原子切换。
- 小程序将在 runtime 上线后上传体验版 `0.8.62`；现有自动化不提交审核、不正式发布。

## 回滚

- runtime 和 H5 的直接回滚点在切换前从生产软链读取，并与四份 root-only env 备份一起写入发布证据。
- 不自动回滚 SQLite、PostgreSQL 或 MinIO；数据异常先冻结现场，再按本次已验证快照决定恢复。
- 小程序体验版回滚为重新指定或上传上一可用体验版；上传成功不等于真机声学验收。
