# 微信小程序网关与伙伴资源修复 Release 20260725-132228

## 发布目标

- 将已提交的原生微信小程序媒体网关首次部署到生产：Control API 对
  `client.platform=miniprogram` 返回短期 gateway ticket，网关以受限 WSS 连接既有
  Cascade Agent。
- 修复小程序伙伴图片由动态路径引用时被微信开发者工具依赖分析过滤的问题。显式将
  `assets/companions/alpha` 纳入体验包，同时以回归测试锁定该约束。
- H5 没有源码改动；本次只切换 runtime，H5 工件仅参与候选 smoke 和发布清单验证。

## 发布范围与边界

- 运行时固定为 Agent、Control API、Speaker Model 与 `miniprogram-gateway` 四个 amd64
  镜像；不得在生产服务器构建镜像。
- gateway WSS 固定使用已备案域名
  `wss://aigcnice.com:8443/memoria-mini-media/v1/mini-program/media`，不向小程序返回
  旧的 IP 地址入口。
- gateway 独立使用 `/etc/memoria-miniprogram-gateway.env`；票据签名材料只存在于
  Control API 与 gateway 环境文件，均保持 `root:root 0600`。
- Nginx 仅公开精确的媒体 WSS 路由，ticket 不进入 URL 或访问日志；WMS 路由和数据不在
  本次范围内。

## 发布前验证

- 小程序逻辑测试 9/9 通过，所有小程序 JavaScript 通过 `node --check`。
- gateway ticket、Control API session、gateway 协议/桥接、生产 Compose 与候选环境合同
  定向测试 95 项通过。
- 生产切流前必须完成 commit-bound source/image/H5 工件校验、隔离 smoke、SQLite 快照、
  四份最小权限环境候选、Nginx 语法检查和 readiness/provider 门禁。

## 验收与回滚

- 公网 `health/ready` 必须返回本 release tag；已认证小程序创建 session 时必须返回
  `media_gateway.websocket_url`、短期 ticket 和 cascade 后端，且不得返回 LiveKit
  participant token。
- WSS 仅验证握手与 ticket，不将 ticket 写入日志；随后在微信开发者工具上传新的体验版，
  验证伙伴机身图片与语音入口。
- 任一 runtime、readiness、provider 或网关验证失败，恢复上一个 runtime、三份既有 env
  与本次 gateway env 回滚点；不自动回滚用户数据。
