# 小程序游客浏览与微信登录 Release 20260728-170236

## 目的

小程序启动后不再强制登录。陪伴、回顾和“我的”三个主 Tab 可直接浏览；用户开始对话、
生成回顾、修改资料、进入数字分身或管理语音授权时，才进入微信登录。

本 release 同时建立与 EchoLife 兼容的微信身份边界，但不在缺少正式旧生产数据源时执行
EchoLife 用户导入。

## 实现

- 小程序新增统一 `auth-gate`，保留受保护操作的返回路径。
- 首次登录使用 `wx.login`、手机号授权、昵称和头像；已建立身份的用户可静默恢复。
- 短期 access token、到期时间和最小身份快照持久化；401 会立即清理本地身份。
- 全局 `authEpoch` 约束私有异步回调，登出、401 或重新登录后，迟到的回顾、资料、统计、
  隐私授权和数字分身响应不得重新写回游客页。
- Control API 新增微信登录、头像上传/读取和微信注销复核；手机号只保存独立 HMAC 与脱敏值。
- 微信平台 access token 命中 `40014/42001` 时清除缓存并只重取一次。
- 外部身份绑定拒绝 openid 与已绑定手机号发生跨账号接管；注销处理中身份不能重新创建会话。
- 新增 EchoLife JSON/SQLite 幂等迁移脚本；正式写入前使用 SQLite backup API 创建
  `0600` 回滚副本，旧故事和时间线只记为 deferred。
- Nginx 新增微信登录、头像上传和头像读取的精确路由；头像公开基址固定为
  `https://aigcnice.com:8443/memoria-api`。
