# Release 20260717-194500

## 目标

完成 P1 5–8：adaptive interruption、级联边想边说/工具同 generation、Omni 动态反馈门禁、固定人设声。

## 变更

### P1-5 Turn Detector + adaptive interruption
- 自建档案默认 `interruption.mode=adaptive`（仍可用 `LIVEKIT_ADAPTIVE_INTERRUPTION=false` 回退 VAD）。
- Turn Detector 继续 `v1-mini`。

### P1-6 边想边说 + 工具同 generation
- 流式分句首段等待 180→120ms / hard 320→260ms，首句更快上嘴。
- `stream_speak_while_think=true` 标志；`first_phrase_ready` 带 generation_id。
- 工具口述结果绑定**同一** GenerationFence（`tool_result_same_generation`）。
- LiveKit `PREEMPTIVE_GENERATION` 仍默认 false（历史卡 thinking 风险）。

### P1-7 AEC/RTP 质量门禁
- Omni 去掉固定 500ms；`computeFeedbackGuardMs(RTP)`：干净路径 ~180ms，脏路径 ~650ms。
- 诊断事件带 `guard_ms` 与 metrics 摘要。

### P1-8 Memoria 人设声
- Omni 默认音色 `Cherry` + `persona` 配置（`Memoria 人设声`）。
- 支持 `QWEN_OMNI_VOICE_CLONE_ID` 接入 DashScope 克隆音色 id（有则覆盖 preset）。
