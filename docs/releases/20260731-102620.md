# 实时查询完成态 Release 20260731-102620

## 目标与根因

- 修复“南京天气 → 我查一下 → 人呢”断接：原生 Qwen 联网流可正常结束在过渡语，旧运行时将其
  视为完整回答，既没有可靠结果校验，也没有受 generation fence 保护的待完成请求。
- 修复催办被当作独立闲聊：public/uncertain 上下文的隐私隔离应继续存在，但相邻同一 public
  scope 的“人呢／查到了吗”等短催办必须能恢复上一条未完成的实时请求。

## 实现与边界

- 实时问题缓冲至本轮结果结束后再播报；桥接语、明确联网失败和独立闲聊式空答统一安全降级为
  “我不知道。”，不再承诺查询后静默结束。
- 待办仅绑定同一 session、相邻 turn 的 generation fence 和 `owner/public` scope；新话题、迟到
  generation 或跨 scope 均清除，不能带入主人历史、私有记忆、工具或投影。
- realtime buffer 复用既有语音字数/句数上限；达到上限立即关闭 provider stream，正式播报仍只
  消费一次既有输出预算。
- 仅切换 runtime；H5 保持 `20260730-233824`，小程序不上传、不提审、不发布。

## 发布前门禁

- Python 全量测试、定向多轮回归、Ruff、strict mypy、H5 `253/253` 与 production build 通过。
- 发布工件必须由本 tag 的干净 source commit 构建，包含 source、四个 amd64 runtime 镜像、候选
  H5、manifest 与独立 verifier；即使 H5 不切换，也保留其工件合同与隔离 smoke。
- 切流前重新读取 runtime/H5 软链，新建 SQLite、PostgreSQL 和四份 root-only env 备份；runtime
  或 Provider/readiness 异常时先恢复 env，再原子切回发布前 runtime，不自动回滚数据。
