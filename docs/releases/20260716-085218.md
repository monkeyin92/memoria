## 修复内容

线上会话曾在用户说话后停留于 `thinking`。生产日志确认 LiveKit 的 preemptive generation 在用户 turn commit 前启动 LLM，捕获 generation `0`；turn commit 随后把 fence 提升到 generation `1`，首个 Qwen token 因此被当作 stale 输出丢弃。

本次最小修复：

1. typed 与 fallback 两套 production turn 配置均关闭 preemptive generation，使 turn hook 先提交 fence，再启动本轮 LLM。
2. 状态机允许 `THINKING` 中的真实新 VAD 进入 `USER_SPEAKING`，避免下一轮字幕触发非法 `thinking + turn_end`。
3. 增加 production wiring、commit-before-first-token 和 THINKING 新轮次回归测试。

迟到 final 字幕的同一物理语音轮次合并不在本次止血范围；需要 LiveKit speech epoch/metrics 的独立设计和测试，不能用简单文本去重替代。
