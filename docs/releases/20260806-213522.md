# Doubao 字幕比例对齐门禁 Release 20260806-213522

## 根因与修复

- 候选 `20260806-211652` 的真实 Doubao provider smoke 在部分批准设计音色得到稳定的
  340–514 ms 原始字幕/PCM 末尾漂移；最高相对误差约 16.2%。原先仅以 300 ms 绝对阈值
  判断，错误地把可线性校准的长语音标记为 `degraded`。
- 共享的 `align_subtitle_words` 现在同时检查绝对和相对误差：原样 `ok` 要求 `<=120 ms`
  且 `<=20%`；缩放 `scaled` 要求 `<=700 ms` 且 `<=20%`；其余仍为 `degraded`，不会生成
  精确 actual-heard 字幕。

## 回归范围

- 协议单测覆盖长语音 500 ms / 14.3% 漂移可缩放、短语音 500 ms / 33.3% 漂移拒绝，以及
  超过 700 ms 的绝对误差拒绝。
- Doubao mock 改为一秒 PCM 的真实比例场景，端到端覆盖 `scaled` 与 `degraded` 回调和
  precise transcript 发布边界。
- 不启用 StreamCore、coturn 或 media-runtime profile；生产仍保持
  `python_authoritative + LiveKit`，只有所有真实 provider/readiness 通过后才切 H5。

## 部署结果

本节在 artifact 验签、隔离 smoke、runtime 切换、真实 provider/readiness 和公网验收后补录。
