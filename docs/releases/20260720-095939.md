# H5 Release 20260720-095939

## 目标

修复已有匿名身份原地注册后，H5 长时间停留在“正在准备你的陪伴空间”的问题。本次仅发布本机构建的 H5 静态产物，不修改或重启 runtime、Control API、Agent、LiveKit 和数据服务。

## 根因与修复

- 后端按 ADR 0004 保留匿名身份原 `user_id`，注册只把同一数据主体升级为注册账号。
- H5 原实现注册成功后无条件把 `profileReady` 设为 `false`，而 Profile effect 只在 `userId` 改变时执行；同 ID 升级因此无法重新进入 ready。
- 修复后以稳定 `user_id` 作为主体数据失效键：同 ID 注册保留已经加载的 Profile，只更新身份和令牌；登录到不同 ID 时仍隐藏旧 Profile，并等待新 Profile 完成加载。
