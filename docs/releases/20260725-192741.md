# 小程序真机伙伴、打断与字幕归属修复 Release 20260725-192741

## 发布目标

- 让五个伙伴资源在微信真机 WebView 中稳定显示，不再只剩 CSS 面部与外圈。
- 在 Agent 播放期间检测到真实用户输入时立即降低下行音量，为打断识别腾出声学空间。
- 拒绝延迟到达的助手回声，并让小程序实时对话只消费 Agent 权威字幕，避免助手内容被标成“你”。

## 变更

- 将小程序实际引用的伙伴与星空背景转换为本地 PNG，并通过字面量路径与 `packOptions.include` 固定进入上传包；回归测试禁止页面重新引用本地 WebP。
- Agent 在播放期候选输入出现时发布 `assistant_audio: duck`，在误触发、拒绝、超时、确认打断和播放结束等对称路径恢复音量。
- 助手回声保护窗口延长至 10 秒，短语气词保护仍保持 800 毫秒，避免把延迟扬声器回声提交成用户话轮。
- 小程序增加共享 WebAudio GainNode，执行 Agent 的 duck/restore 控制；实时对话忽略网关原始 transcription 和未确认的用户 interim，只显示 Agent 权威事件。
