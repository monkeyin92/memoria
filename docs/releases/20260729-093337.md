# 类型化记忆、情节整合与技能域 Release 20260729-093337

## 目标

在保留不可变证据账本和动态工作记忆的前提下，完成长期记忆 P0～P4：

- 分离 `memory_kind / domain_category / item_kind`；
- 扩展类型化搜索投影、时间、实体、重要度、敏感度和冲突信息；
- 建立固定中文记忆评测集；
- 跨会话合并同一人生事件，并保留全部证据；
- 建立需要主人审批和单次确认的可执行 Skill Domain；
- 将 Mem0 与 TurboVec 限制在影子评测和实验索引；
- 固定 pgvector 维度并按模型建立 partial HNSW。

## 数据与安全边界

- `archive_evidence_events` 继续是权威来源，派生投影可重建。
- 工作记忆只按当前话轮、权限和预算动态组装，不写入长期记忆表。
- Mem0 不写权威记忆；TurboVec 不承担唯一索引或权限判断。
- Skill 只有经账户主人审批后才能进入可执行状态；每次运行仍需确认，并记录步骤、结果和逆序补偿。
- 账户导出、删除和恢复合同覆盖 Skill 持久状态与新增投影。
