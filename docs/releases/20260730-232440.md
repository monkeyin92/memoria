# 当前发言展示与文字退出按钮 Release 20260730-232440

## 发布目标

- H5“退出文字对话”恢复为带图标、边框、背景和 44px 点击高度的明确按钮。
- H5 与小程序对话区只展示当前说话对象：用户发送后显示用户内容，助手开始流式回答后立即替换
  为助手内容，不再堆叠本场或上一场的语音、文字记录。

  文字模式作为临时展示，权威终稿到达后覆盖，语音模式继续忽略。
