# 20260808-161814 Release

## 变更摘要

Agent 自我进化控制面：三层验证、候选生命周期、receipt 签名与删除竞态防护。

参考《AI Agent 深入理解》第 8 章，实现完整的 Agent 自我进化控制面。

## 核心能力

- **LearningSignal**：三层轨迹验证（result/process/quality）+ 防刷重复证据
- **CandidateArtifact**：四种载体（knowledge/prompt/skill/harness/parameter）
- **候选生命周期**：candidate → validated → canary → stable，支持回滚
- **EvolutionResolver**：运行时接线，只允许 low risk + allowlist 任务族

## 安全边界

- owner-private / global-redacted 权限隔离，global 使用字段白名单
- Receipt 签名：HMAC-SHA256 绑定 account/fence/speaker/query/artifacts
- Archive 验证 receipt 一致性，失败不计入进化信号
- 删除竞态防护：tombstone + read lease + resolver 三次检查

## PostgreSQL + RLS

- `services/evolution/postgres_schema.sql`：完整 schema + RLS policies
- `infra/postgres/init-memoria.sh`：挂载 002-evolution-schema.sql
- `scripts/upgrade_evolution_postgres.sh`：幂等升级脚本
- memoria_controller（DDL+DML）vs memoria_app（只读+initialize_schema=False）
