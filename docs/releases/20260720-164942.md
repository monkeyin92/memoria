# Runtime Hotfix 20260720-164942

## 目标

修复真实账号在“注销账号”时返回 `500 Internal Server Error`、删除请求停在第一步且后台重试无法推进的问题，并让已经进入 `deleting` 的请求在部署后自动恢复完成。

## 根因与修复

- 账号存在 29 条历史语音会话记录，其中部分 LiveKit 房间早已自然过期。
- 删除治理在终止历史会话时调用 LiveKit `DeleteRoom`；LiveKit 对不存在的房间返回 `404 not_found`，原适配器将其作为致命异常抛出，导致请求停在 `started`，接口冒泡为 500。
- `LiveKitRoomCloser` 现在只把明确的 `not_found + HTTP 404` 视为“房间已经关闭”的幂等成功；认证失败、服务不可用及其他异常仍继续抛出，由删除重试机制处理。
- 回归测试同时锁定缺失房间可继续删除，以及非 404 异常不得被吞掉。
