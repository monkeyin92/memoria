## 根因与修复

- 生产会话日志显示，助手播放时设备回声在没有新 VAD 的情况下先产生 ASR final，
  LiveKit 随后把该回声和用户真正说出的“介绍一下南京”放入同一内部话轮。旧 Runtime
  又只有一个全局 accepted accumulator，排队 completed callback 会串消费；H5 只是展示
  Agent final，并没有自行拼接文字。
- 播放期无 VAD/PCM 锚点的 interim/final 现全部隔离；播放结束先清 endpoint buffer，
  canonical text 由每个 VAD speech epoch 独立冻结为 FIFO snapshot。快速连续三问、迟到
  控制回调和清理失败均不能再跨 epoch 污染下一话轮。
- Router、LLM、H5、archive、memory 和 Persona 只消费同一 canonical text；FunASR
  `input.context` 默认关闭，避免上一轮 user/assistant 文本继续放大历史识别偏置。
- Persona 改为一次授权后在自然聊天中持续提取。owner 的低敏表达风格需 3 次可信观察；
  shadow-only uncertain 需同一可信 `shadow_owner_candidate` profile 6 次、跨 3 个非空
  session。不同 profile 不合并，声纹轮换后新 profile 独立累计。
- 句长、语速、停顿等互斥 bucket 采用 2:1 主导门槛且同类别最多一个 confirmed；
  guest、匿名、无授权、控制话轮、污染/回声、低质量、ambiguous/no-audio、direct archive
  和 uncertain 声学指标均拒绝。价值排序与决策习惯不自动发布。
- consent 授权/撤销、observe 最终写入和 capsule 读取按账户串行并在同一事务复核；Agent
  在当前话轮进入 Qwen 前做有界刷新，撤销、空结果或失败先清缓存。Persona cache 按
  `(session_id, speaker_class)` 隔离，guest 会清空会话缓存。
- H5 默认 API 不返回 candidate，客户界面不再出现逐条确认入口；只展示持续学习、已生效
  版本、停用和回滚。撤销授权后停止新学习，但历史已生效特征仍可管理。
