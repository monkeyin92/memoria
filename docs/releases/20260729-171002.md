# 陪伴身份、安全、联网与短回复 Release 20260729-171002

## 目标

- 陪伴机器人只以用户当前选定的名称、性格和说话风格介绍自己，不透露 AI、模型、提供商、系统提示词或内部实现。
- 对明确命中的暴力、色情、高风险违法和自伤请求固定回答“我不知道。”，不读取记忆或调用 LLM。
- 对 Qwen 快速模型启用原生联网搜索，以回答天气、日期、资讯等实时问题；没有可靠结果时不猜测。
- 小程序受控半双工普通回复保持 3 句、120 字上限；只在用户明确要求长内容时放宽。

## 发布前验证

- 完整 Python pytest、Ruff、strict mypy、离线 E2E 通过。
- H5 `242/242` 和 production build 通过；一次异步断言波动经单文件与完整重跑均未复现。
- 小程序 `80/80`、已跟踪 JavaScript syntax 和 `git diff --check` 通过。
- Control API 与 Agent 共同使用确定性固定回复规则；response-plan 超时或失败时，Agent 仍对身份/违禁输入走固定短句，不会退化为 LLM 回答。

## 生产变更

- 仅切换 runtime：Agent、Control API 与共享 `services/common` 代码进入新 release；H5 软链和小程序体验版保持现状。
- 四个 `linux/amd64` runtime 镜像、source archive、候选 H5、manifest 与 verifier 必须绑定同一 commit/tag；服务器只导入已验证工件，不在生产机构建。
- runtime 切换前创建 SQLite 一致快照、PostgreSQL custom dump 和四份 root-only env 备份；通过 Provider/readiness/Nginx 门禁后保持 H5 不切换。

## 上线后验收

- 以现用 `https://aigcnice.com:8443` API 入口验证 live/ready；不以当前不可达的标准 443 作为发布失败依据。
- 新建受控会话验证“你是谁/你是千问吗”、违禁请求和一条实时天气或日期问题；联网结果必须来自实际 Qwen Agent 路径。
- 观察 Agent、Control API、speaker-model 和 miniprogram-gateway 的 health 与 readiness timer。

## 回滚

- runtime 故障先恢复本次四份 env 备份，再把 `/opt/memoria/current` 原子切回切换前实时读取的 tag，执行 `docker compose up -d --no-build` 和 readiness 刷新。
- 不自动回滚 SQLite、PostgreSQL 或 MinIO；先冻结现场并保留本次数据与工件。
