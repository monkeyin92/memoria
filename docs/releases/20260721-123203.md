## 变更

- 级联主链切换为 FunASR Realtime + 百炼 Qwen + 豆包 Seed-TTS 2.0 双向流式。
- 双向会话直接接收 LLM 增量短语；正常完成复用连接，打断发送 `CancelSession` 后
  关闭并淘汰连接，session shutdown 显式关闭预热池。
- 生产 WebSocket 只允许 `wss://`，禁止 userinfo、fragment、半套或双套鉴权；生产
  只部署 APP ID + Access Token，不部署火山 Secret Key。
- 五个伙伴默认音色改为阳光青年、甜美桃子、温柔小雅、高冷沉稳、深夜播客 2.0；
  供应商 speaker ID 只由 Agent 内置批准 registry 解析。
- 历史 CosyVoice clone 继续支持查看、试听、评估和撤销；豆包模式拒绝新的激活请求，
  历史 active 运行时回退所选伙伴音色。Control API 镜像保留历史预览 registry。
- readiness 和真实 provider smoke 改为验证豆包 PCM、24 kHz/mono、字时间戳、
  `CancelSession` 写入、连接关闭和 active binding 清除。
