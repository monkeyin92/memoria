# Release 20260717-113441

## 目标

在保持 `20260717-111241` 话轮稳定性、1.50 秒级联 endpointing 与 Omni/Cascade 架构隔离的前提下，让两条语音链路更接近 GPT Live 的“边组织边说、直接问题不拖沓、笑声安全互相感染”。

## 实现

- 级联 `SpeechPlan` 增加当前话轮 `delivery_mode`：
  - `direct`：直接回答，`neutral/0.98`；
  - `deliberative`：高置信度安排/规划请求，当前 LLM 上下文副本加入一次 4–12 字短衔接指令，CosyVoice rate 降至 0.95；
  - `light_laughter`：主转写有笑声、当前 Qwen3-ASR 声学标签为 `happy` 且无严肃信号时，允许同一回答内一次短笑，使用 `happy/0.98`；
  - `supportive`：负向情绪或事故、诈骗、医疗、求助等严肃语境，禁止笑、咳嗽和轻佻填充词，rate 不高于 0.94。
- DeliveryPlan 只作用于当前 generation，不进入长期记忆；结构化日志只记录 mode、合法 emotion、rate 与 turn id，不记录转写正文。
- Preamble 与正文继续使用同一个 LLM generation 和同一个 CosyVoice 双向流任务，不拆成两次回答。
- Omni session instructions 加入两个对比示例：口语训练可用一次短 preamble，日期问题必须直接回答；同时要求能自然发笑才笑，不能就直接温暖回应，不把“哈哈”逐字念出来，并避免整段匀速朗读。
- 未启用 listener cue、SSML、Qwen-Audio-TTS、MiniCPM、MiniMax 或新依赖；咳嗽不实施。
