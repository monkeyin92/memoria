# 小程序播放期打断与当前发言展示修复 Release 20260725-203826

## 发布目标

- 用户在 Agent 播放期间说出“停一下”等明确控制语时，立即调用已接线的 LiveKit 停止播放，
  而不是只降低音量或恢复打断阈值。
- 小程序“实时对话”只保留当前已确认发言，避免历史行不断叠加导致页面无限变长。
- “我的”页在未选择或尚未加载伙伴资料时，显示一个与默认伙伴配色一致的中性表情。

## 变更

- `DuplexRuntime` 复用既有的唯一播放停止回调：播放期被输入保护接受的明确控制语在 interim
  阶段即可触发停止；普通输入仍等待 final transcript，声纹聚焦路径及其 owner/guest 策略
  不变。
- 小程序实时字幕将新权威事件直接替换当前显示项；仍只接受 Agent 确认的用户终稿，避免把
  网关原始转写或延迟助手回声标成“你”。
- 资料页复用现有伙伴脸部坐标，叠加默认眨眼、眼睛和嘴巴，不再依赖完整图片本身带有表情。

## 发布前验证

- 先以失败回归复现“停一下”只恢复阈值、不调用停止回调；修复后针对
  `DuplexRuntime → VAD → interim transcript → LiveKit stop` 的测试通过。
- Agent production wiring、TargetSpeakerFocus、PlaybackInputGuard、UtteranceRouter 与
  小程序网关相关测试通过；Ruff、strict mypy、JavaScript 语法检查和
  `git diff --check` 通过。
- 小程序逻辑测试 15/15 通过，覆盖实时区域只替换当前项及资料页默认表情。
- 微信开发者工具匿名会话已实际编译：主页显示“仅显示当前发言”，资料页默认伙伴显示眼睛
  和嘴巴，控制台编译错误为 0。

## 发布边界

- runtime 继续按四个固定 amd64 镜像的 commit-bound 工件发布；H5 没有源码改动，只参与
  候选 smoke 与发布清单校验，不切换 H5 软链。
- 本次将上传新的微信小程序体验版，不提交审核或正式发布。
- 开发者工具与合成上行不能替代真实 iOS/Android 的扬声器回声消除、物理麦克风打断、
  弱网、前后台和蓝牙验收；发布后仍需在最新体验版真机复测。
