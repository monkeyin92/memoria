# 小程序真机伙伴与语音上行修复 Release 20260725-161522

## 发布目标

- 在新体验版中稳定保留五个伙伴的完整机身资源，消除真机主页只显示 CSS 面部占位的问题。
- 让微信小程序上传的 PCM 音频以 LiveKit 麦克风音轨进入既有 Cascade Agent，消除“AI 能说话、但听不到用户”的单向会话。

## 变更

- 小程序主页和资料页均使用伙伴图片的字面量资源路径；五个 `alpha` 图片和星空背景已纳入源代码。回归测试同时拒绝主页与资料页重新使用动态资源路径。
- 网关发布本地 PCM 音轨时明确指定 `TrackPublishOptions(source=SOURCE_MICROPHONE)`。Agent 的音频输入只接受该类型，避免上行帧被忽略。
- 本轮同时提交当前小程序视觉与资料页改动；未纳入本次提交的本地设计预览、未引用备用资源和工作目录保持不变。

## 发布前验证

- 网关 bridge/app/protocol 定向测试通过；Ruff 和 strict mypy 通过。
- 小程序测试 9/9 通过；主页、资料页脚本语法检查与 `git diff --check` 通过。
- 微信开发者工具在匿名会话中实测完整显示星澜机身图片，控制台为 0 个编译错误。

## 发布边界

- runtime 仍以四个固定 amd64 镜像发布；H5 无源码变更，只保留工件校验和候选 smoke，不切换 H5 软链。
- 小程序将上传体验版 `0.8.40`，不提交审核或正式发布。
- 新体验版上线后仍需用真实 iOS/Android 复验用户录音、扬声器/AEC、弱网、前后台与蓝牙；开发者工具模拟器不提供可用于该结论的录音帧。
