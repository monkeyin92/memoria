# 小程序真机伙伴与语音上行修复 Release 20260725-161522

## 发布目标

- 在新体验版中稳定保留五个伙伴的完整机身资源，消除真机主页只显示 CSS 面部占位的问题。

- 小程序主页和资料页均使用伙伴图片的字面量资源路径；五个 `alpha` 图片和星空背景已纳入源代码。回归测试同时拒绝主页与资料页重新使用动态资源路径。

- 本轮同时提交当前小程序视觉与资料页改动；未纳入本次提交的本地设计预览、未引用备用资源和工作目录保持不变。
