# Release 20260823-210222-voice-fix

**Date**: 2026-08-23  
**Type**: Agent Component (Quick Release)  
**Base**: 20260821-224710-denoising-full

## Summary

Quick fix release addressing three critical voice interaction issues reported in production testing.

## Changes

### Voice Interaction Improvements

1. **Improved Speech Recognition Stability**
   - Disabled `skip_stage2_on_silence` to ensure consistent deep denoising for low-volume speech
   - Increased VAD threshold from 0.3 to 0.5 to reduce false triggers from ambient noise
   - Increased silence timeout from 1.5s to 2.0s to avoid premature cutoff

2. **AI Interruption Support**
   - Integrated SPEAKING state transitions in output stream
   - Added `start_speaking()` and `stop_speaking()` methods to MediaAudioIngress
   - State machine now properly tracks AI playback state
   - Enables interruption based on `allow_interruption` configuration

3. **Disabled Auto-Listening Mode**
   - Removed automatic transition to LISTENING state on session initialization
   - Sessions now start in IDLE state
   - Requires explicit trigger (button press or wake word) to activate listening
   - Prevents background conversations from triggering the system
