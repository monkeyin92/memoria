# Memoria 20260720-203120

## 本次变更

- 修复 CosyVoice 流式 PCM 按 WebSocket 分片独立归一化导致的音量跳变和 click。
- 新增 `TargetSpeakerFocus`：正式 SpeakerAuthority 会话先完成目标说话人聚焦，再提交话轮或停止播放；shadow 候选仍保持 `uncertain` 权限。
- 播放期移除 VAD 触发的即时 duck/restore，旁人或回声不会再造成连续音量抽动。
- 归档 session event 对仅时间戳变化的重试按幂等成功处理，避免关闭阶段的重复事件阻塞。
- H5 发布保留历史 immutable hash assets，防止旧标签页请求懒加载分片时 404。

## 运行边界

- CAM++ 仍为 shadow-only；`TargetSpeakerFocus` 只控制当前交互，不授予私人记忆、长期写入或敏感动作权限。
- 真实手机的噪声、重叠说话、TCP 媒体丢包和主观听感仍需设备验收，不能由 HTTP 或本地测试替代。
