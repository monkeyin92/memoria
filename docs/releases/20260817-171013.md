# Memoria Runtime Release 20260817-171013

## 发布目标

- 为小程序提供受主体能力门禁保护的对话回顾窄投影。
- 将 Actual Heard、记忆候选和已确认记忆分成互斥分区，避免把生成但未播放的内容或未确认候选直接当作主人记忆。
- 收口候选记忆确认路径，并补齐跨账号及 adult/minor/unknown/missing 主体矩阵。

## 发布范围

- Control API：新增 GET /v1/archive/conversation-review，并为记忆确认写入复用 conversation_review capability 门禁。
- 微信小程序：新增 Memory Review 页面投影、确认后权威重拉、auth epoch/游客清理保护及对应测试。
- Agent：仅补充 PR-16 Tool cancel / heard text cutoff 回归测试；不需要切换 Agent/Bridge 运行代际。
- H5、ESP32 固件、Media Edge、Voice Core Bridge 和设备身份区不切换、不刷写、不触发设备语音。

## 发布前门禁

- Control API archive 全文件测试通过；相关主体/能力矩阵测试通过。
- Agent Tool cancel、provider timed-text cutoff 回归通过。
- 小程序全量测试 150/150 通过。
- Ruff、strict MyPy（399 个源码文件）、模块预算和 git diff --check 通过。

## 验收边界

本 release 只推进控制面 code/wired/local verified；不把本地窄投影证据写成精确 DAC、真实设备 Actual Heard、AEC、Double-talk、T1–T14 或 full_duplex_verified 通过。生产切流后仍需单独记录 API readiness、容器健康、错误日志和回滚证据。

## 回滚

- 部署前冻结服务器当前 runtime、env、数据快照和 root-only rollback receipt。
- H5 保持现有软链；若 Control API readiness、容器健康或业务探针失败，按 docs/production-deployment.md 的完整 runtime 回滚流程恢复旧 runtime/env。
- 本 release 不执行破坏性数据库迁移，不自动回滚 PostgreSQL、SQLite 或 MinIO 数据。
