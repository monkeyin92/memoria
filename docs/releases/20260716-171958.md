# Release 20260716-171958

## 范围与根因

- 仅发布 Control API 与 Agent Runtime；H5 继续使用 `20260716-150805`。
- LiveKit、Nginx、证书、防火墙、443/8443 和 7882/UDP 策略均未修改。
- 生产中的连续自说自话来自扬声器回灌：助手音频被 FunASR 当作用户 final，再次提交 turn。上一候选版还遗漏了播放结束后的英文短回声，并用固定 `min_words=5` 损害了真实短打断。

## Agent 编排修复

- 播放期输入继续先暂停、后判定；只有真实打断才推进 generation，虚假候选恢复同一段播放。
- 播放结束后 800ms 内也匹配助手英文回声，例如助手刚说过 `It's a good idea.` 时，FunASR 返回 `it's` 不再创建新 turn。
- 守卫原因固定分类为 `backchannel`、`non_target_language`、`assistant_echo` 和 `feedback_circuit_open`，写入会话内计数与结构化日志。生产当前没有启动或对外暴露 Prometheus endpoint。
- 自建档案恢复 `min_words=0` 和 `false_interruption_timeout=1.20s`。助手播放期间临时把 LiveKit `min_words` 提高到 1000；守卫确认“停”“等等”“不是”等真实短打断后恢复为 0，再交给 LiveKit EOT 提交。
- 回复最多 3 句、96 个有效字符；即使 LLM 首段本身超长，也会在 96 个有效字符处截断。
- preemptive generation 保持关闭，turn commit 提升 GenerationFence 后才启动本轮 LLM。
