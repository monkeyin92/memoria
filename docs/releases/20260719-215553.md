## Readiness 权限修复

原候选在真实 Provider smoke 全部成功后，由 Agent one-off 执行 `verify_env --mark-smokes-passed`；Agent env 按最小权限没有 `MEMORIA_AUTH_SECRET`，因此标记失败。

本 release 将职责拆开：

- Agent one-off 只执行 `python -m scripts.verify_env`。
- Control API one-off 执行 `python -m scripts.mark_readiness`，使用 `/etc/memoria-control-api.env` 中的内部认证材料提交 smoke evidence 并立即复查 ready。
- `MEMORIA_AUTH_SECRET` 没有加入 Agent env。

定向验证：18 项 pytest、Ruff 与两个 shell 脚本的 `bash -n` 全部通过。
