## 修复范围

- 普通 `companion` 话轮在提交 generation 后统一绑定当前 TTS 音色快照，避免
  response provenance 因缺少实际音色而在 LLM 前 fail closed。关闭“过滤明显旁人（实验）”
  时，`uncertain / shadow_guest_candidate` 仍按现有权限边界聊天，不升级 owner、私人记忆、
  工具或主人历史资格。
- 同一 speaker epoch 复用唯一分类 task，避免迟到回调以相同确定性 event ID、不同 fence
  重发 `speaker.classified` 并触发 Archive 409。
- waiter 取消通过 `asyncio.shield` 与共享分类 task 隔离；新 VAD epoch 和 runtime close
  仍可取消旧 task，不会把取消结果冻结到下一话轮。
- 更新两个历史语音测试夹具，使其实现当前 Doubao 设计音色的完整审计字段；未新增依赖、
  配置项、数据库迁移或 H5 行为。
