# 百炼 DeepSeek-v4-flash 切换 Release 20260802-135917

## 目标与范围

- 将默认主 LLM、打断语义、中控每日回顾、记忆/Persona 提取切换为百炼
  `bailian_deepseek / deepseek-v4-flash`，复用 `DASHSCOPE_API_KEY`。
- 百炼 OpenAI-compatible 请求使用 `enable_thinking=false`；显式 `qwen` 与直连
  `deepseek` 仅保留兼容覆盖。
- Qwen 专属实时检索不再接线；没有已验证检索器时实时请求 fail-closed 为“我不知道。”。
- 本轮只切换 runtime；H5、小程序源码、体验版和正式版不变。

## 发布前门禁

- 全量 `.venv/bin/pytest -q` 通过。
- `.venv/bin/ruff check .`、`.venv/bin/mypy services --strict`、`compileall` 和
  `git diff --check` 通过。
- readiness SQLite 约束已加入 `bailian_deepseek`，并覆盖旧数据库迁移回归。
- 中断语义门限为 `1.2s`，以覆盖 DeepSeek-v4-flash 实测首轮响应延迟；本机 provider smoke
  因缺少 `DASHSCOPE_API_KEY` 与豆包 TTS 凭据安全跳过；生产切流前
  必须通过真实 FunASR、DeepSeek、Doubao、InterruptSemantic smoke，禁止用 `SKIP` 写入 readiness。

## 部署结果

本候选曾原子切换 runtime，但真实 provider smoke 在 `0.6s` InterruptSemantic 门限处失败；
readiness 未写入，H5 未切换，随后恢复到 `20260731-114616`。Doubao、FunASR、
DeepSeek 主链与 LiveKit 均已通过；失败根因为 DeepSeek-v4-flash 分类响应约
`0.77–0.88s`，修复记录见 `20260802-142257`。
