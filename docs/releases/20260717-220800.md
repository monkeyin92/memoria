# Release 20260717-220800

## 目标

收紧声纹门，拒绝旁边平板/电视视频外放进入对话，同时尽量保留主人近场说话。

## 变更

### 声纹门（tablet/TV bleed）

1. **双窗共识（turn_commit）**：对话回合必须 utterance + rolling 两窗都 ≥ 阈值；不再允许单窗 `score.accepted` 放行。
2. **近场能量门**：注册时记录 `owner_ref_rms`；若本句 voiced RMS < 注册 × 0.32，判 `far_field` 拒绝（平板外放通常更弱）。
3. **连续媒体抬阈值**：rolling 长语音 + 高 duty（≈ 连续播放）时 thr+0.10。
4. **Soft accept 收紧**：仅双窗、非 media、best≥thr 且 worst≥thr−0.02，speech_ms≥700。
5. **嵌入改进**：只对 voiced 帧做 mel；附加前后半段 delta 特征。
6. 默认 `SPEAKER_ACCEPT_THRESHOLD` 0.55 → **0.58**。

## 验收

- 主人近场说话仍可正常问答。
- 旁边平板放视频时，视频台词不应进入用户轮次 / 不应触发回复。
- 日志可见 `speaker_reject reason=far_field|mismatch` 且 `media_like=true` 时 thr 抬高。
