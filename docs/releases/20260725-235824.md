## 根因与修复

- 语音层：TargetSpeakerFocus 将明确控制语延后到 final transcript，真机 endpoint 延迟会让
  AI 继续播放数秒。现在 Router 已确认且有真实 PCM 的 interim 控制语立即启动当前声纹校验，
  通过后走唯一 LiveKit 停止桥接；明确 guest 仍不得打断。
- 发布层：上一候选已在 shell 层加入等待，但 `scripts.mark_readiness` 内部仍在写入 smoke
  后立即检查 `/health/ready`，导致外层等待无法执行。
- 现在 `mark_readiness` 支持仅写入 smoke，`refresh_readiness.sh` 先写入，再等待当前
  release 与 Agent heartbeat 同时 ready；默认 CLI 行为仍保留立即检查，避免影响独立调用。
