# 小程序网关握手可观测性 Release 20260728-123528

## 目的

`20260728-114049` 已将 `handshake_ack` 与 `ready` 时序修复上线，并成功上传小程序体验版
`0.8.56`。但生产 Compose 直接启动 Uvicorn 时，应用模块 logger 继承到 root 的有效级别为
`WARNING`，导致刻意加入的无敏感握手 `INFO` 事件不可见，无法用同一台真机复测区分握手未完成与
LiveKit bridge 建连缓慢。

本 release 仅将 Gateway 的应用 logger 接入 Uvicorn 已配置的 `uvicorn.error` `INFO` handler。
它不改变 ticket 校验、PCM、播放、限流、数据库、H5、Nginx 或小程序包；不需要重新上传体验版。

  H5/API/SQLite restart smoke 已通过；SQLite 双副本与四份 root-only env 回滚副本均已创建。

  InterruptSemantic smoke 已通过。首次 refresh 中语意分类器发生一次 0.6 秒超时，立即重试的

  smoke 为 `close_code=4401`，Gateway 日志已可见无敏感的 `phase=ticket_rejected`。

  `transport=header|hello phase=ack_sent`，成功时后续出现 `phase=ready_sent`。这仍是唯一能确认
  真机连接问题已修复的验收，不以构建、上传或健康检查替代。

## 无 VPN 网络取证

- 同一 iPhone 关闭 VPN 的实时窗口中，TCP SYN 已到达服务器，且两次请求完成 WebSocket Upgrade 并进入
  Gateway；独立宽带的 `8443` TLS/WSS 也获得 `101`。因此当前症状不是全局 DNS、8443 监听、Nginx stream
  或 Gateway 不可用。
- 443 使用 WMS vhost 的同域有效证书，但外部路径仍有 ClientHello 后断开证据；没有在未验证前将小程序
  迁移到 443，也没有修改 WMS 或 `8443` stream。后续只依据本 tag 输出的 `ack_sent`/`ready_sent` 与同机
  原始错误定性，避免把网络猜测当修复。
