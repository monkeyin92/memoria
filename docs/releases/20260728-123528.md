# 小程序网关握手可观测性 Release 20260728-123528

## 目的

`20260728-114049` 已将 `handshake_ack` 与 `ready` 时序修复上线，并成功上传小程序体验版
`0.8.56`。但生产 Compose 直接启动 Uvicorn 时，应用模块 logger 继承到 root 的有效级别为
`WARNING`，导致刻意加入的无敏感握手 `INFO` 事件不可见，无法用同一台真机复测区分握手未完成与
LiveKit bridge 建连缓慢。

本 release 仅将 Gateway 的应用 logger 接入 Uvicorn 已配置的 `uvicorn.error` `INFO` handler。
它不改变 ticket 校验、PCM、播放、限流、数据库、H5、Nginx 或小程序包；不需要重新上传体验版。

## 发布前验证

- `services/miniprogram_gateway/tests/test_app.py`：通过。
- `ruff check services/miniprogram_gateway/app.py`：通过。
- `mypy --strict services/miniprogram_gateway/app.py`：通过。
- `node --check apps/miniprogram/utils/media-gateway.js` 与 `git diff --check`：通过。
- 本地 Uvicorn 默认 logging config 已确认 `uvicorn.error` 的 effective level 为 `INFO`，并经其
  `uvicorn` 父 logger 的 stdout/stderr handler 输出。

## 发布与验收

- 仅切 runtime；H5 保持 `20260723-192611`。
- 直接回滚点为 `20260728-114049`；数据库、PostgreSQL、MinIO 与 Nginx 均不变。
- 发布后需确认四容器 healthy、readiness 绑定本 tag、H5/API/WMS 仍正常。
- 同一 iPhone 使用已上传的 `0.8.56` 点击一次“开始语音陪伴”；Gateway 日志必须可见无敏感的
  `transport=header|hello phase=ack_sent`，成功时后续出现 `phase=ready_sent`。这仍是唯一能确认
  真机连接问题已修复的验收，不以构建、上传或健康检查替代。
