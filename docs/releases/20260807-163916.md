# 实时天气、长对话打断与话轮路由 Release 20260807-163916

## 发布范围

- Open-Meteo 天气回答改为短句；区分当前天气、今天、明天和后天，并按目标日期请求
  `daily` 预报，不再把明天的问题落到今天的数据。
- 实时查询不再被静态“我不知道/我不清楚/我不确定”兜底文本提前截断；天气等可查询问题
  仍会进入后台检索并返回结果。
- 播放期 ASR 的 interim/final 判定重新绑定 canonical 文本和当前 speech epoch；低信息回声
  片段（例如单字或混合解码尾巴）进入 PlaybackInputGuard 隔离，合法短问句和大写产品名不被
  误拦，真实长话轮不消耗 feedback circuit 配额。
- `够了`、`好了`、`行了`、`可以了`、`不用了` 及带“知道了”的结束语统一走
  `UtteranceRouter` 控制路径，并同步 Cascade/Omni 词表。

## 根因证据

- 生产会话 `431dca76-53ac-452f-b390-ab295abb29aa` 中，“明天上海的天气”两次命中今天的
  forecast；旧天气 formatter 同时输出体感、风速和日高低温，造成回答僵硬且过长。
- 同一会话出现 `canonical_user_turn_resolved raw_len=37 canonical_len=0 discarded_epochs=1`，
  以及 `其。`、`对谢ght.` 等播放回声/迟到 ASR 尾巴；interim 的“继续播放”决策还可能被不同
  canonical final 复用。生产默认 `FUNASR_CONTEXT_ENABLED=false`，因此主要问题是播放期门禁和
  generation 绑定，而不是无限增长的 FunASR 上下文。
