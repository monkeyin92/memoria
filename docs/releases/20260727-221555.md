## 发布内容

- 同一 `speech_epoch` 的打断确认语最多发布一次，迟到 ASR 终稿和下一次 VAD
  不再让同一用户话轮重复播放“嗯，你说。”。
- 小程序新增首播、underflow、hard reset 和缺帧 conceal 的有界数值遥测；
  Gateway 严格校验事件名、字段和频率后转发到既有
  `voice-agent.telemetry`，不接受转写、音频、token、cookie 或任意文本。
- WebAudio underflow 改为只重建后续排程，不再硬停仍登记中的旧 source。
- FunASR 支持可选 `FUNASR_VOCABULARY_ID` 和
  `FUNASR_SPEECH_NOISE_THRESHOLD`；生产没有热词表 ID 和真机录音校准证据，
  因此本轮保持未配置。
- 完成度和 TRTC 边界见 `docs/voice-architecture-progress.md`；架构决策见
  `docs/adr/0024-speech-epoch-ack-and-bounded-client-playout-telemetry.md`。
