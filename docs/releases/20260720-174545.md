# H5 Release 20260720-174545

## 目标

修复新用户三段声纹录音在 iPhone Safari 上提示“无法读取这段录音”的问题，并澄清录音提示语不代表存在 ASR 逐字校验。

## 根因与修复

- 失败发生在 H5 本地 `AudioContext.decodeAudioData()`，请求尚未到达 `/v1/speakers/enrollments`。
- Safari 的 `MediaRecorder` 可能生成浏览器可录制但无法被同一页面即时解码的 fragmented MP4；服务端声纹模型本身只接受 16 kHz 单声道裸 `pcm_s16le`。
- onboarding 现在用 Web Audio `ScriptProcessor` 直接采集、合并并下采样为 16 kHz 单声道 PCM，再提交声纹接口，绕过容器解码。
- 录音过短、没有有效音频或不在 1.5–15 秒范围内时，会提示重新录制。
- 当前声纹登记是 text-independent、shadow-only；没有 ASR 逐句内容一致性接口。界面改为“参考每句话”，并明确只检查时长、清晰度和声学质量。
