# H5 Release 20260720-162553

## 目标

在“我的”页提供可发现的“注销账号”入口，复用既有全账户删除治理链路。用户输入当前密码和精确确认短语后，永久删除账号、对话、回顾、人格、声纹、声音样本与供应商资产；成功后清空浏览器登录态和实时会话，返回注册页。

## 实现与隔离

- 新增复用的 `AccountDeletionForm`；“我的”页使用底部危险操作弹层，“数字心智与声音”原有删除区继续复用同一表单和 API。
- 注销期间禁用关闭与 Escape，背景内容不可交互，主导航退出无障碍树；失败时在弹层内显示服务端错误。
- `useVoiceSession.reset()` 清空旧账号字幕、错误、音频诊断、情绪与麦克风状态，同时断开实时连接；普通“结束对话”仍保留原有语义。
- Profile、回顾请求、字幕持久化和离线消息补发均增加当前账号归属校验，迟到的旧账号任务不能在注销后重新写回 UI 或本地缓存。
- 服务端回归覆盖同一用户名注销后重新注册：返回新 `user_id`、空历史和 `companion_id=null`，重新进入伙伴选择与声纹初始化。
