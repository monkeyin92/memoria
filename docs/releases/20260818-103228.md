# Memoria Runtime Release 20260818-103228

## 发布目标

- 修复主体 category/age 权威事实不完整时形成 `confirmed + unknown` 非法混合态的问题，统一降级为完整 `unknown_safe`。
- 将绑定归属 `subject_id` 与当前 Runtime Profile 主体 `active_subject_id` 分离，并让 Direct JWT 显式携带空主体 fence。
- 冻结设备媒体重连的 account/device/client/subject/binding/profile authority，仅允许 `stream_epoch` 递增。
- 在 Provider epoch reset 失败时同时清理 Registry 与新 Bridge epoch，避免半切换 runtime 残留。

## 授权范围

- 切换：Control API（含 Session Runtime）、Agent、Voice Core Media Bridge、Go Media Edge。
- 不切换：ESP32 固件、Nginx、H5、小程序、PostgreSQL、Redis、MinIO、LiveKit、Speaker Model 与两个兼容 Gateway。
- Control API 启动时仅执行向后兼容的 SQLite nullable `active_subject_id` 加列及旧行一次性回填；不执行 PostgreSQL migration。
