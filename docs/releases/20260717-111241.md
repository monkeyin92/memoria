# Release 20260717-111241

## 范围

- 在不改变 1.50 秒级联 endpointing、Omni WebRTC 状态机和两条链路隔离的前提下，收紧自然口语提示词。
- Omni 与级联仅在多步骤安排、查询或真实推理时使用一句短思考式开场；直接问题、简单确认和情绪倾诉不添加填充词，相邻轮次避免重复同一 opener。
- 轻松安全语境允许一次短促轻笑；难过、生气、害怕、求助或严肃风险语境禁止笑和咳嗽。
- CosyVoice `happy` 语速从 1.04 降至 0.98；`longanyang` 只接收阿里云固定 Instruct 格式与合法七类情绪。
- Qwen3-ASR 情绪旁路按不同 `turn_id` 累积声学证据；单次笑声转写不直接推导开心音色，情绪与 SpeechPlan 日志不记录转写正文。
- 删除 Qwen3.5 不保证支持的 `smooth_output`，也不再要求 Omni 在用户说话期间主动附和。
